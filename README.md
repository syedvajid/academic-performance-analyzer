# 📊 Academic Performance Analyzer

An end-to-end Machine Learning project for analyzing and predicting student academic performance using Python and Scikit-learn.

---

## 🎯 Project Objective

This project aims to analyze student academic data and build machine learning models that can predict academic performance based on various factors such as study hours, attendance, previous grades, sleep patterns, and more.

---

## 🛠️ Technologies

- Python
- Pandas
- NumPy
- Matplotlib
- Scikit-learn
- Streamlit

---

## 🚀 Planned Features

- Data Cleaning
- Exploratory Data Analysis (EDA)
- Feature Engineering
- Model Training
- Model Evaluation
- Performance Comparison
- Interactive Prediction App
- Model Deployment
